## Search Form
- **Search field dropdown** with options:
  - Entire entry
  - Headword (with alternate spellings)
  - Headword (preferred spelling only)
  - Definition and notes
  - Etymology
  - Associated quotes and manuscripts
  - Modern English word equivalent
- **Text input** with placeholder "search for"
- **Keyboard dropdown button** (special character selection):
  - SVG icon: `keyboard-grey-*.svg`
  - Dropdown menu items:
    - `Þ þ (thorn)`
    - `Ð ð (eth)`
    - `Ʒ ʒ (yogh)`
    - `Æ æ (ash)`
  - Each is a link with `href="#"` (JavaScript inserts character into search field)
- **Search button**
