### Entry Info Section
- **Forms**: Extensive list of variant spellings
- **Etymology**: `OE winnan; sg.3 winneð, winð; p. wan(n, won(n; pl. wunnon; ppl. -wunnen`

### Definitions (Senses and Subsenses)
Each sense has:
1. **Sense number** (1, 2, 3a, 3b, 4, 5, 6a, etc.)
2. **Definition text** with subsenses labeled (a), (b), (c), etc.
3. **Show/Hide Quotations** toggle per sense
4. **Associated quotations** grouped by subsense letter

### Quotation Format
Each quotation shows:
- **Date + source abbreviation** (linked to bibliography):
  - e.g., `[c1175 Orm.(Jun 1)](/m/middle-english-dictionary/bibliography/BIB2677?rid=hyp.733.19981211t105002)`
- **Line/page reference**: `16019`
- **Quotation text**: Middle English with editorial marks
  - e.g., `All iss turrnedd to þatt an, To winnenn affterr ahhte.`

### Key Patterns
- Links to bibliography use format: `/bibliography/BIB{id}?rid=hyp.{id}.{timestamp}`
- Quotations use `þ` (thorn), `ð` (eth), `ʒ` (yogh), `ȝ` (yogh variant) extensively
- Editorial brackets: `[...]` for expansions, `(...)` for scribal additions
- Multiple manuscript witnesses cited per sense
